# Greek named display schemes · A2.2b · 2026-11-03

Status: implemented for modern monotonic Greek; automated fixtures checked. Human/native linguistic
and independent standards review **not performed**. Full ISO 843 compliance is not claimed.

## Sources, editions and exact scope

- [UNGEGN Greek report, version 4.0, March 2016](https://unstats.un.org/unsd/ungegn/working_groups/wg5/documents/wgrr4greek.pdf),
  pages 1–2: the UN-approved ELOT 743 **transcription** table and its contextual notes. Selector:
  **ELOT 743 · Type 2**. This is transcription without the optional reversibility sub-macrons,
  not the older BGN 1962 system and not phonetic prediction (γκ stays gk; ντ stays nt).
- [ISO 843:1997 preview](https://cdn.standards.iteh.ai/samples/5215/ebfdc4425f834833a5fe07c44f2dca79/ISO-843-1997.pdf),
  printed pages 2–4, tables 1–2 and notes: **Type 1 transliteration**, with η→ī and ω→ō,
  independent consonants and αυ/ευ/ου→au/eu/ou. Selector explicitly says **ISO 843:1997 · Type 1**.
  This differs from the Type 2 transcription often called “ISO/ELOT” on passport converters.
  Cached tables were rendered and visually read because PDF text extraction mangled Greek glyphs.

Both cached references came from the user-approved A2 source batch; retained bytes/hashes are in
[6-23-A2-SOURCES.json](../6-23-A2-SOURCES.json). No new download, copied converter implementation,
dependency, dictionary rebuild or learner-text change. Existing alphabet-lesson conversions remain.

## Rules and independent fixtures

`greek.test.ts` stores the 24 alphabet table cells plus final sigma as literal input/expected pairs,
with their uppercase cells. The UN report's note 2 combinations (αι, άι, αϊ, γκ, ει, έι, εϊ, ντ, οι,
όι, οϊ, υι), contextual table cells and ISO table 1 note 1 au/eu/ou pairs are literal fixtures.
The standard's note 11 examples Chara/Thalassa/Psari check title case (the Greek strings are plain
reverse renderings for those Latin examples, not quotations of a published Greek passage).

Separate synthetic tests exercise every voiced/unvoiced context, initial/medial/final μπ, stress
movement for ELOT αυ/ευ/ηυ, diaeresis/first-vowel stress breaking pairs, ού→oú, NFD equivalence,
macron+acute, uppercase digraphs, unsupported input and stale per-language settings. Tests do not
derive expected table values from the engine. Reader rendering checks that selected Greek spelling
wins over an older supplied reading, keeps source spans intact, and declines unsupported words.

## Limits and remaining review

The engine accepts modern letters with acute/diaeresis, retains written stress, and does not guess
an unwritten accent or modern pronunciation. It declines whole polytonic/archaic words, rather than
silently dropping breathing marks, iota subscripts or unknown Greek letters. The limitation is shown
beside the selector. Historical symbols, numerical notation and ISO punctuation conversion are not
implemented; this feature supplies word readings, retaining the learner's original punctuation.
This is not a reversible text-conversion tool or an official passport/name validator.

Browser observations and checks belong in [6-23-A2-GREEK.md](../6-23-A2-GREEK.md). Native review,
polytonic support and the full A2 surface/position/reveal/fading acceptance remain open.
