## BGN/PCGN 1947 (PCGN validity check, November 2022)

[Official table](https://assets.publishing.service.gov.uk/media/636cd2828fa8f5357a0c652c/ROMANIZATION_OF_RUSSIAN_2022_final.pdf),
pages 1–3. Character map plus note 1/2 contextual e/ye and ë/yë; note 3 middle-dot distinctions;
note 5 case preservation. The code does not infer an unwritten ё. Stress marks are omitted from
the display conversion. Golden fixtures transcribed from the examples: Екатеринбург, Ёлкино,
Змеевка, Ульяновск, Лукъяновка, Щурово, Донское, Грозный. The synthetic note-3/case/boundary
regressions are identified separately in the test. Curly signs follow the table's U+2019/U+201D.

## ISO 9:1995, Russian subset

[Publisher preview of the standard](https://cdn.standards.iteh.ai/samples/3589/3b8e97e9a40c4e668f22b30a0735fd4a/ISO-9-1995.pdf),
Table 1, pages 2–5 (Russian entries only). Golden fixtures from that table: муж, нижний,
общество, часы, щит, альбом, это, южный, яма. This is the modern Russian alphabet; the engine
refuses other Cyrillic letters instead of presenting a partially converted word. Not an assertion
of support for every Cyrillic language or historical Russian spelling.

## A2.2a · ALA-LC 2012 and ICAO passport-letter spelling

ALA-LC uses the complete 37-letter table in the already cached LC Word/PDF source. Both PDF pages
were rendered and visually read because text extraction omits the tied glyph cells. Every upper/
lower table cell is an independent golden fixture; tied capitals are T͡S / I͡E / I͡U / I͡A. Four obsolete
letters are supported in this scheme only. Terminal hard sign is retained in the 2012 edition:
[LC's revision explanation](https://www.loc.gov/catdir/cpso/roman_bulgarian_russian_proposal.html).
Composed word/case/stress tests are synthetic, not described as published word examples.

Passport choice: ICAO Doc 9303 Part 3, eighth edition 2021 with the amendments listed in the cached
source, §6 B, printed pages 27–28. Its 32 modern Russian letter cells are independent golden
fixtures (including Ё→E, Й→I, Ъ→IE, Ю→IU, Я→IA). The soft sign is absent from this table and from
[the official consular passport table](https://dk.kdmid.ru/documents/Transliteraciya-kirillicheskih-znakov.pdf)
linked under passports [by the consular office](https://dk.kdmid.ru/ru/consular-functions/blanki-zayavleniy-i-obraztsy-dokumentov/).
The conversion omits it rather than inventing a Latin letter; that is a separately identified
composition regression, not a published character-pair fixture. This makes converted Cyrillic
letters uppercase but preserves punctuation/non-Cyrillic text: a display spelling choice, not a
full MRZ encoder, passport-field validator or assurance of an individual's official name spelling.
The consular PDF was read by the web renderer; direct curl retrieval returned 403, so no cache/hash
is claimed for that additional source. The already cached ICAO source remains reproducible.

The two new choices extend the existing saved Russian setting. The preview now includes Щит,

interface languages, written locally. Original alphabet-lesson romanizeRu/data are unchanged.
